# tools/viz — the AC19 gap visualization

A gap is silence, and silence is invisible to a sighted judge watching a
3-minute video. These two renders make the mechanism visible. Both are built
offline from C7 data: `pipeline/gaps.ts` (`parseWebVtt` → `mergeSpeech` →
`findGaps` → `clipToContent` → `splitIntoCues`) run over the asset's real
subtitles and manifest. Every figure on screen is computed by that code at
render time — nothing is typed in.

    npm run viz            # both renders
    npm run viz:timeline   # the strip only (no film needed)
    npm run viz:split      # the split-screen clip (needs the film, see below)
    npm run viz:check      # tsc over tools/viz

## 1. The timeline strip — `docs/video/gap-timeline-{video,readme}.{svg,png}`

The whole film as one strip: dialogue blocks, the silences that qualify as gaps
(≥ `limits.ad.min_gap_ms`), long gaps split into consecutive cue windows
(≤ `limits.ad.max_cue_ms`), windows dropped for carrying fewer than
`limits.ad.min_useful_words`, silences rejected for being under the minimum,
and the spans outside the manifest's content windows (credits). The `video`
variant is 1920×1080 with a zoom inset; the `readme` variant is 1200 px wide
without it.

The SVG is generated by `timeline.ts` with no dependency. It is rasterized with
whatever the machine has: `rsvg-convert` if present, else ImageMagick
(`magick`). ImageMagick's own SVG renderer resolves `font-family` through a type
map it does not ship with, so `raster.ts` writes one into `generated/viz/` from
the first regular+bold TTF pair it finds (macOS Arial, Liberation, DejaVu). It
also drops the stroke on `<rect>` and paints `<pattern>` fills black, which is
why every outline and hatch in these renders is made of `<line>`s.

Options: `--manifest <path>` (default `media/tears-of-steel.manifest.json`),
`--verbosity concise|standard|detailed` (default `standard`; the cue count
varies by level, by design — see `limits.ad.min_useful_words`), `--out <dir>`.

## 2. The split-screen before/after — `docs/video/gap-split-screen.mp4`

30 s of the film, 1280×720. Top: the film as shipped — a `SILENCE` badge during
each cue window, because that is what a blind viewer gets there. Bottom: the
same seconds with Interstice — the film ducked to `limits.ad.duck_target_pct`
with a `limits.ad.duck_ramp_ms` ramp (one expression in `t`, applied both to
the audio `volume` and to the level bar), the description as a caption inside
the window, the window's word budget beside it, and a playhead moving over a
mini timeline of the clip range. What you hear is the bottom panel.

ffmpeg composes it; `split.ts` reads the C7 data, writes the overlay SVGs,
rasterizes them, writes the full command to
`generated/viz/split/ffmpeg-command.txt`, and runs it. This machine's ffmpeg
has no `drawtext` and does not re-evaluate `drawbox` per frame, so all text is
PNG overlays switched with `enable='between(t,…)'`, and the level bar is a PNG
that slides under an opaque shield.

**The film is never committed** (`media/*.mp4` is gitignored). Pass it:

    npm run viz:split -- --film /path/to/tears-of-steel.mp4
    INTERSTICE_FILM=/path/to/tears-of-steel.mp4 npm run viz:split

Options: `--from <s> --to <s>` (default 215–245: gap 9 at 3:37, gap 10 at
3:47, and the 1.5 s gap at 3:58 that `standard` drops as too short for three
words), `--track <track.json>`, `--dry-run` (write the command, do not run
ffmpeg).

**Description audio.** If a `contracts.description_track` file exists —
`--track`, or `media/<asset_id>.<verbosity>.track.json` beside the asset — its
cue text becomes the caption and its clip (`audio_uri`, relative to the track
file) is mixed over the ducked film. If not, the caption reads **PLACEHOLDER**
in orange, the film is only ducked, and the log line says so:
`INTERSTICE.viz.split.track none … → PLACEHOLDER captions`. Re-run once the
generated track lands and the clip is rebuilt with the real cue.

The clip is copied to `docs/video/` only when it is ≤ 3 MB; otherwise it stays
under `generated/viz/split/` and the log says `INTERSTICE.viz.split.tooLarge`.
