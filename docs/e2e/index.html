What this report cannot show

  • Audible ducking. The trace shows the volume property set and restored. Whether a listener hears the film get quieter is checked on hardware.
  • VoiceView. It cannot be switched on in the Virtual Device. "What the viewer is told" below is what the app hands to the screen reader, not what the screen reader did with it.
  • The memory bound on a real Fire TV. Every run here is on the Virtual Device.
  • That a cue avoids dialogue. Fixture windows are declared, not derived from subtitles; that half waits on the generated track.
